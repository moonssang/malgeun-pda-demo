# 맑은물에 FIELD · 모바일 PDA v2

[공개 데모 바로가기](https://malgeun-mobile-pda.moonssang031.chatgpt.site) · [촬영용 샘플 라벨](https://malgeun-mobile-pda.moonssang031.chatgpt.site/labels.html)

GitHub의 Code → Download ZIP으로 전체 코드를 내려받을 수 있습니다.

원자재·부자재·완제품의 입출고, 카메라 연속 스캔 및 일괄 등록, 재고, LOT 추적을 통합한 모바일 웹 데모입니다. 운영 ERP 코드나 DB를 포함하지 않습니다.

## 실행 / 배포
dist/를 HTTP 또는 HTTPS 정적 서버로 제공하세요. 빌드나 npm 설치가 필요 없습니다. ES modules 때문에 파일을 직접 더블클릭해서 실행하지 않습니다. GitHub Pages 배포는 dist/ 내용을 배포 루트로 사용합니다. Node 20 이상에서 `npm test`, `npm run check`로 16개 테스트와 구문 검사를 실행합니다.

## 현장 작업
1. 홈에서 원자재 / 부자재 / 완제품 업무 선택.
2. 입고 또는 출고 지시 열기. 창고·LOT·수량 확인. 완제품 출고는 차량과 온도 확인.
3. 연속 스캔 시작 → 카메라 시작 → 여러 라벨을 차례로 촬영.
4. 미등록 보관함에서 수량 확인·잘못된 스캔 삭제.
5. 스캔 보관함 확인 → 일괄 등록 → 입출고 확정.

스캔마다 ERP에 저장하지 않습니다. 보관함은 이 브라우저의 임시 작업이며, 일괄 등록 한 번으로 가상 ERP 내역을 반영합니다. 원자재·부자재는 확정 때 재고를 반영하고 완제품 출고는 일괄 등록 때 차감한 뒤 확정 때 중복 차감하지 않습니다.

원자재 입고는 25kg 라벨 2개(50kg), 부자재 출고는 100EA 라벨 3개(300EA), 완제품 출고는 10EA 라벨 3개(30EA)로 체험합니다. 완제품 목록의 '대량 출고 · 30 BOX'는 30개 포장 라벨(300EA)을 누적합니다. 카메라 없이 샘플 라벨 버튼과 '다음 10개 라벨 연속 추가 (시연)'도 사용할 수 있습니다.

## 스마트폰 카메라
- 공개 HTTPS 주소를 휴대폰 Chrome/Safari 등에서 엽니다. 사용자가 카메라 시작을 누르고 권한을 허용합니다.
- 영상은 서버로 전송하지 않습니다. 기본 BarcodeDetector가 지원되면 사용하고 미지원 브라우저에서는 포함된 ZXing으로 처리합니다.
- labels.html을 PC나 다른 기기에 열거나 인쇄하여 촬영하세요. 앱의 '라벨·수량 기준'에서도 열 수 있습니다.
- 상품/BOX 코드는 화면 밖으로 뺐다가 다음 실물을 비춰야 새 스캔으로 셉니다. 고유 포장 ID는 중복 검증합니다. SKU만으로 물리적으로 같은 포장인지 완전히 판별할 수 없습니다.
- 카메라 없음·권한 거절 등을 안내하고 샘플·키보드 입력을 제공합니다. 스캔창 종료·메뉴 이동·백그라운드 전환 시 스트림을 종료합니다.
- 실제 기종별 초점·조도·곡면·반사·스캔 속도는 현장 검증이 필요합니다. 자동 검증은 합성 카메라 스트림과 실제 디코더를 사용했으며 하드웨어 성능 측정이 아닙니다.

## 바코드 / 수량
- 상품: 가상 EAN-13. EA 품목은 1EA. 원자재 kg 상품은 실측 중량 입력 필요.
- BOX-FP-001 등: 상품과 패킹 수량 연결. LOT는 작업에서 선택.
- PK-P1-0001 등: 가상 고유 포장 ID. 품목·LOT·포장수량을 데모 마스터에서 조회.
- 실제 ERP 관리 화면과 필드는 확인했으나 운영 바코드와 라벨 샘플이 연결된 것은 아닙니다.

## LOT 추적 / 알림
원자재·부자재 입고 → 생산 투입 → 완제품 LOT → 납품처를 가상 이벤트 그래프로 표시합니다. RM-261020, SM-261022, FP-261024-A 예시를 사용하세요. 연결이 없으면 이력 없음으로 표시하고 날짜·품목만으로 추정하지 않습니다. 정/역방향 추적, 기록 상세, 품질 알림·관련 LOT 출고 보류를 시연할 수 있습니다.

신규 작업·검수 오류·재고 기준 미달·소비기한·완료 알림, 읽음 처리·관련 화면 이동을 제공합니다.

## 구현 경계
실제 ERP API/DB/인증/운영 데이터/백그라운드 푸시는 연결하지 않았습니다. LOT 계보·위치·고유 포장체계·품질 보류는 설계용 가상 기능입니다. 로컬 ERP 소스에서 확인한 재고 반영 시점을 모사합니다. 모든 품목·거래처·수량은 가상, 업무 기준일은 2026-10-26으로 고정했습니다.

브라우저 localStorage v2를 사용하며 v1 상태를 덮어쓰지 않습니다. 설정 → 시연 데이터 초기화로 다시 시작합니다.
